# 考试身份核查系统

NestJS + SQLite 后端，React + antd 前端。员工用手机核查考生身份（学号 / 姓名 / 座位号 / 大头照），管理员在电脑后台实时接收异常上报并与员工在线沟通。

## 快速开始

```bash
npm run setup     # 安装依赖（需 Node 20+）
npm run build     # 构建前端与后端
npm start         # 启动，默认端口 3000
```

正式部署（考场局域网 / Linux 服务器 + Nginx / Docker）、备份恢复、忘记密码等见 **[DEPLOY.md](DEPLOY.md)**。

启动日志会打印局域网地址，例如 `http://192.168.0.109:3000`，员工手机连同一 Wi-Fi 打开即可。

- 默认管理员：`admin / admin123`，首次登录后请在右上角「修改密码」
- 数据目录：`server/data/`（SQLite 数据库 `identify.db` + 压缩后的照片），备份时复制整个目录即可

### 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | 3000 | 端口 |
| `DATA_DIR` | `server/data` | 数据库与照片目录 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | admin / admin123 | 仅在没有管理员时用于创建初始账号 |
| `JWT_SECRET` | 首次启动随机生成并保存在数据目录 | 登录令牌签名密钥 |

### 开发模式

```bash
npm run dev:server   # 后端 :3000，热重载
npm run dev:web      # 前端 :5173，/api 与 /socket.io 代理到 :3000
```

## 使用流程

1. **管理员**（电脑）→ 考试管理 → 新建考试
2. **导入名单**：上传 Excel。格式参照「选拔作业」的 **最终** 表：表头含 `学号`、`名称/姓名`，可选 `座位号`、`序号`；座位号可空，其他列（分数等）自动忽略。多个工作表时默认选「最终」，也可手动选择。弹窗内可下载模板。之后可重复上传：
   - 合并更新：按学号新增 / 更新，保留已有核查结果
   - 覆盖：同上，并删除表中不存在的考生
3. **上传照片**：把以学号命名的照片（`260450101.jpg`）打包成 zip 上传，弹窗内可下载模板。支持 jpg / png / bmp / webp / heic、子文件夹、上千张大图。照片按学号全局保存，所有考试共用，重复上传会覆盖
4. **账号管理**：新建或「批量生成员工账号」（如 jk01 ~ jk20，随机密码），分配负责的考试，复制或下载 CSV 下发给员工。停用账号或重置密码会让该账号立即下线
5. **员工**（手机）登录 → 选考试 → 名单（可搜索学号 / 姓名 / 座位号，按状态筛选）→ 点开考生核对大头照：
   - **正常**：一键提交，自动跳到下一位未核查考生
   - **有问题**：选择 作弊 / 替考 / 其他（「其他」必须填写说明），提交后管理员立刻收到提醒
   - 右下角悬浮按钮：与管理员实时对话，可附带当前考生信息，带快捷短语
6. **管理员右侧实时面板**：
   - 实时动态：所有核查记录实时推送，异常会弹窗并响铃（窗口不在前台时发桌面通知），可直接「处理」，处理意见会自动发给上报员工
   - 员工消息：每个员工一个会话，显示在线状态和未读数
7. **导出结果**：考试详情页 →「导出结果」生成 Excel

## 技术要点

- **实时通信**：socket.io，优先使用 WebSocket，网络不支持时自动降级为 HTTP 长轮询；断线自动重连，重连后自动补拉数据，断线期间每 10 秒轮询一次
- **图片加载优化**：
  - 上传时用 sharp 生成两档 WebP：列表缩略图 160×220（约 3KB），核查大图 720×960（约 20-40KB）。实测 1016 张、650MB 原图压缩后共 22MB，处理耗时约 12 秒
  - 照片 URL 带版本号，以 `immutable` 长缓存，同一张图只下载一次
  - 列表懒加载 + 分批渲染；核查页预加载接下来的考生大图
  - 自动按 EXIF 方向旋转；BMP 由内置解码器处理
  - 前端按角色拆包，员工手机不会下载管理后台代码；静态资源 gzip 压缩并长期缓存
- **权限**：照片和接口都需要登录；员工只能访问分配给自己且已启用的考试
- **审计**：每次核查、重置、处理都写入 `check_logs`，可在考试详情页「核查记录」查看
